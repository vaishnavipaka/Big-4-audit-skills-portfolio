# Big 4 Audit Skills Portfolio — Titan Company Ltd. (FY2023-FY2025)

Three connected audit & finance projects built around one real company (Titan Company Ltd.), 
demonstrating the core skills listed in Big 4 audit/finance job postings: internal controls 
testing, SQL-based transaction analysis, and financial statement review.

## Project 1: Internal Controls Testing
**File:** `Titan_Internal_Controls_Testing_Project 1.xlsx`

Built a Risk & Control Matrix identifying Titan's key audit risk areas (gold/inventory 
valuation, revenue recognition, related-party transactions, Gold Exchange Programme), with 
control activities and test procedures for each.

## Project 2: SQL Anomaly Detection
**Files:** `queries.sql- anomaly-detection` + result screenshots (`Screenshot 2026-08-25 164409.png`, 
`164500.png`, `164530.png`, `164551.png`)

Wrote SQL queries against a 507-transaction payments dataset to detect duplicate payments, 
round-number amounts, weekend postings, and vendor concentration risk. Screenshots show each 
query's actual output run in MySQL Workbench.

## Project 3: Financial Statement Review & Variance Analysis
**File:** `Titan_Financial_Statement project 3.xlsx`

Built a formula-driven Excel model analyzing Titan's real FY2023-FY2025 financials — YoY 
variance, profitability/leverage ratios, and a written fluctuation analysis. See the 
'Integrated Summary' tab inside this file for how all 3 projects connect.

## Integrated Summary

Project 1's Risk & Control Matrix flagged gold/inventory valuation as Titan's most significant 
audit risk area. Project 3's financial statement review confirms this risk is materializing in 
real numbers: Inventory Days rose from 176 to 217 over FY24-25, tying up increasing cash. To 
fund this — alongside broader growth — Titan more than doubled its borrowings and drew down its 
investment reserves, shifting from a majority equity-funded to a majority debt-funded balance 
sheet, with Interest Coverage falling sharply. Project 2's transaction-level testing surfaced 
real gaps in the payment control environment (duplicate payments, unusual round-number entries) 
— meaning that at precisely the time Titan is under increasing financial pressure from its 
growth strategy, the basic operational controls meant to safeguard cash outflows are not yet 
airtight. Together, these three workstreams tell one integrated story: a company financing rapid 
growth in a genuinely risky category increasingly through debt, while foundational payment 
controls still need strengthening.
